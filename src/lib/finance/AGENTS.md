- Unified finance: Phase 2 and isolated source contracts use injected mock-only RLS/provider transports. getUnifiedFinanceReport checks the current role, then returns disabled while UNIFIED_FINANCE_ENDPOINT_ENABLED is false and performs no finance reads. While that constant is true the same handler builds the reviewed report from existing RLS evidence, a read-only Stripe list of balance transactions, payouts and charges, and the existing per-vehicle profitability columns. Verified Collections cards are complete only when every in-period item matches; unmatched items keep the card blank and show a count. Operating Expenses counts vehicle_expenses and maintenance company share once each movement is dated, exact cents, and allocated to a vehicle; a linked service expense is not added again. Operating Result is Net Collections minus Operating Expenses only when both are complete. Customer Compensation stays blank: there is no customer credit source and no compensation-note source. Posted Ledger stays incomplete without verified C1 rows. No new SQL is required. Unknown visibility/kinds and unclassified C1 expenses fail closed with incomplete coverage; known Owner exclusions preserve only Manager operating scope. The finance session observer extends only the existing session-isolation hook, and only while UNIFIED_FINANCE_ENDPOINT_ENABLED is true. While that constant is false the root listener stays the production path: no finance cache clears, no delayed-startup rejection, and no second subscriber. The manager screen is its own admin tab, not an Overview panel. Per-vehicle maintenance cents skip a service when a vehicle_expenses row names it through maintenance_record_id; the linked expense is the one count. That skip runs only inside the unified-finance report, which stays off, so it has no live effect. The same vehicle_pl exclusion is proposed SQL only and is not applied; live vehicle_pl is unchanged until that SQL is approved.
- Monthly Owner P&L: the only P&L screen. Owners only, and only while OWNER_PNL_ENABLED is true (a constant, currently true). getOwnerPnl returns disabled before the owner check and before any table or Stripe read while it is false; a direct link falls back to Overview and the tab is omitted. The screen is one Eastern Time month beside the previous month. Income is verified Stripe charges from readLivePartnerCharges (no second Stripe list) plus recorded non-Stripe payments: paid or refunded, revenue types, deposits excluded. A recorded row is the same transaction as a charge when they share a PaymentIntent id, a charge id, an invoice id, or metadata paymentIds. Amounts are never compared. The charge is kept. A Stripe-method row with none of those references is unmatched, excluded, and the month shows Partial Coverage. Income is shown by source: Stripe, Cash App, Zelle, Venmo, Wire, Cash, and Other. Unattributed charges stay off the net. Expenses are grouped by vehicle_expenses.category. A linked service and its expense count once. Maintenance uses company_share, or total_cost when the share is blank. A share that disagrees with the linked expense is a note, and the expense is counted once. Each vehicle has income, refunds, expenses, and net. Stripe fees stay on the company net. Refunds are payment_refunds rows; a refund of a deposit is excluded. Stripe processing fees and refund fees are balance transactions for that Eastern Time month, listed with balanceTransactions.list through createReadOnlyStripe and the month's created window. stripe-reader.server.ts is unchanged. A fee-type transaction contributes its net, and every other type contributes the negative of its fee. That cash impact is negated into a cost and subtracted from net. A failed or truncated read shows Fees as Unavailable and the net as Partial. Net is income minus refunds minus expenses minus that fee cost. A 100-page directory cap withholds the report as "P&L records were incomplete". CSV and Print are built in the browser. The dedupe stays in owner-pnl.ts until payment-reporting.ts is the shared helper. finance-monthly-pl.ts is not mounted and still does not subtract Stripe fees. No writes, no SQL, and no email.
